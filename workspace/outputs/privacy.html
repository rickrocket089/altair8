This website does not use cookies, does not run any analytics or tracking software, does not embed any third-party content (fonts, videos, social widgets), and does not operate any contact forms. It is a static site: what you see is what gets sent to your browser, nothing more.

3. Server log files (hosting)

This website is hosted by DomainFactory GmbH, a German hosting provider, acting as our data processor. Each time this site is accessed, the web server automatically records a standard access log entry, including:

  • IP address of the requesting device
  • Date and time of access
  • The page or file requested
  • Browser type and operating system

This data is processed to technically deliver the website, ensure system security and stability, and investigate misuse in case of an attack. The legal basis is our legitimate interest under Art. 6(1)(f) GDPR. This log data is not merged with any other data source and is not used to identify individual visitors. It is retained only as long as necessary for these purposes and then automatically deleted.
