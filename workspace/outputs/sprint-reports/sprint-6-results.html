Define Objectives of a Solution / Sprint 6

Principled Reasoning, or Confabulation?

Naledi's pilot test: give Claude and GPT the same content, then change only the audience or the goal. Does the visual form they choose — and the reasoning they give for it — actually shift to track that change, or does it stay templated regardless?

Reviewed & approved — revised once by Ingrid before being marked usable. Answers Ingrid's own open question from Sprint 4.

Key insights
  1. 01

    Partially principled, not confabulated — but directional, not quantifiable. Both models produced reasoning that tracked the manipulated variable, named specific rejected alternatives, and invoked real cognitive-science mechanisms rather than generic boilerplate. Six data points can generate this hypothesis; they can't put a number on how often it holds.

  2. 02

    The strongest signal was a categorical medium switch, not a chart tweak. Claude dropped charts entirely for new support reps who needed context, not a decision — and explicitly reasoned that a chart "would imply a need to analyze," which wasn't the goal.

  3. 03

    The weakest signal has a name now: "medium-frame anchoring." GPT reasoned audience-sensitively about chart complexity for the same scenario, but never exited the "which chart" frame to ask whether any chart was the right medium at all.

  4. 04

    This pilot informs, not decides. It's one input into the founder's solution-direction call (an added reasoning layer vs. a genuinely new visualization language) — not sufficient on its own to make that call, or any architecture decision.

Design caveat, found after publishing: Pairs A and B don't isolate a single variable as cleanly as intended — changing the audience (Pair A) naturally changes the implied goal too, and vice versa for Pair B. Only Pair C holds a variable (audience wording) literally identical. Not a flaw in the finding, but a reason to read "audience varies" / "goal varies" as bundled, realistic scenario pairs rather than a strict factorial design. Sprint 7's adversarial-pairs test is designed to isolate this more cleanly.

Naledi's direct answer to Ingrid's Sprint 4 question

Partially principled reasoning, not pure confabulation — but this is directional evidence, not a quantifiable probability. Six data points can generate this hypothesis; they can't quantify how often it holds. That's what Sprint 7's adversarial-pairs test is for.

Pilot only: 3 pairs, 6 variants, one run each, scored by Naledi herself (not blind — a flagged bias risk). Reviewed by Ingrid: revise before use, not block — the original form-prediction probe had a flaw (specific, internally-consistent reasoning could predict the form even if generated post-hoc). Sprint 7's redesigned test is adversarial pairs: scenarios where the obvious/canonical form is wrong for the stated audience or goal. If a model picks the non-canonical form and its reasoning explicitly overrides content convention for audience/goal reasons, that's real evidence the reasoning does causal work — not just retroactive description.
